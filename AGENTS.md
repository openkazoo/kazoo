## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues (`openkazoo/kazoo`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Only `wontfix` maps to a real label (`Won't Fix`); the other four canonical triage roles have no label in this repo. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout — one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
