# Hard fork from 2600Hz Kazoo

Upstream `2600hz/kazoo` went effectively dormant (no meaningful evolution since
~2020, no updates since early 2024). We chose a hard fork rather than
soft-forking or upstreaming patches, because it lets us modernize the build and
runtime environment and consolidate scattered community forks into one actively
maintained codebase without waiting on upstream review that is unlikely to come.
